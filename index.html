github+picgo+typora图床配置

发表于 2024-05-29

Github

  1. 新建一个仓库，选择Public，其他都不需要。
  2. 点击设置的developer settings

3.选择Personal access tokens的 Tokens(classic)选项。

4.点击Generate new token (classic)

5.设置 Expiration 为 no expiration，永不过期。

6.在Select scopes选项中只勾选repo仓库一栏。

7.接下来你会得到一个token用于picgo，记得先把token保存，只有第一次能显示token。

Picgo

1.在github上找到picgo的release：Release 2.3.1 · Molunerfinn/PicGo (github.com)

2.下载setup.exe文件，并安装。

3.下好后你会看到这个界面

选择图床设置-github：

  • 仓库名为 username/reponame

  • 分支名一般为默认的 master

  • token为以上github生成的token

  • 存储路径随意

  • 自定义域名：cdn加速，格式为 https://jsd.onmicrosoft.cn/gh/[username]/[reponame]

Typora

1.要在typora中应用上传图片到图床，需要打开菜单栏的文件-偏好设置-图像

2.修改插入图片时的动作为上传图片

3.接下来选择上传服务：Picgo(app)

路径为你所下载的Picgo.exe。

然后就完成了，这样在插入截屏的图片时就会自动上传图片到图床，并且引用也会自动更改，用hexo更新的博客就没问题了。
